# Nice Gadgets online store — Galera Team

A responsive product catalog built with **React**, **TypeScript**, and **Redux Toolkit**, following the **Atomic Design** methodology. Deployed on **Netlify**.

## 📦 Features

- 📱 Responsive design for all devices
- 🛒 Shopping cart functionality
- 💡 Light/Dark theme toggle
- 🧱 Atomic Design structure
- 🌐 REST API integration
- 🗂️ Advanced pagination, sorting, and filtering options
- 👋 Welcome animation on first visit
- ⚖️ Product comparison page
- 🖱️ Custom scrollbar styling
- 🎞️ Product image sliders

---

## 🧬 Technologies Used
- **React** with **TypeScript**
- **Redux Toolkit** for state management
- **SCSS Modules**
- **React Router**
- **MUI (Material-UI)**
- **Swiper** library for sliders
- **Axios** for HTTP requests
- **REST API** integration
- **Atomic Design architecture**
- **Netlify** for deployment
- **ESLint** for code linting
- **Prettier** for code formatting

## 🗂️ Project Structure

The project follows the **Atomic Design** approach:

```
src/
├── design/
│   ├── atoms/
│   ├── molecules/
│   ├── organisms/
│   └── templates/
├── store/          # Redux slices
├── pages/
├── utils/
├── styles/
├── services/          # API calls
├── App.tsx
├── root.tsx          # Router
└── main.tsx
```

## ⚙️ Getting Started

1. **Clone the repository**  
   `git clone https://github.com/FSJAN25-team2/Product_catalog_Galera_team.git`

2. **Install dependencies**  
   `npm install`

3. **Run the development server**  
   `npm run dev`

4. **Build for production**  
   `npm run build`
